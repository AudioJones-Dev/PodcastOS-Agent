# Riverside Feature Benchmark Notes

## Purpose

Capture useful product inspiration from Riverside-style platforms while keeping Podcast OS focused on agency production operations.

## Useful Feature Categories to Study

### Recording and Session Management

Riverside-style products make it easy to schedule, join, record, and manage remote sessions.

Podcast OS relevance:

- Host and guest prep
- Recording details
- Session readiness
- Raw file handoff

MVP decision:

- Track recording sessions and links.
- Do not build native recording first.

### Media Library

Media platforms organize recordings, clips, exports, and transcripts.

Podcast OS relevance:

- Episode deliverables
- Raw asset references
- Clip packages
- Final exports

MVP decision:

- Use file/link references first.
- Add native storage later.

### Clips and Repurposing

Clip workflows are important for podcast-led content marketing.

Podcast OS relevance:

- Clip moment log
- Clip package status
- Social caption workflow
- Approval before publishing

MVP decision:

- Track clip tasks and deliverables.
- Do not build a clip editor first.

### Collaboration and Review

Review comments, approvals, and version state are central to production.

Podcast OS relevance:

- Client approvals
- Internal reviews
- Revision requests
- Deliverable versions

MVP decision:

- Build approval and revision workflow early.

### Publishing and Distribution

Riverside-style platforms often connect media creation to publishing workflows.

Podcast OS relevance:

- Publishing checklist
- Distribution log
- Channel status
- Analytics readiness

MVP decision:

- Start with manual publishing checklists and URL logs.
- Add API integrations later.

## Strategic Difference

Riverside is media-production-first.

Podcast OS should be operating-system-first:

- Agency setup
- Client setup
- Work assignment
- Approval gates
- Deliverable tracking
- Client visibility
- Reporting and refresh loops

## Product Rule

Do not copy a recording platform before the production operations layer is clear and useful.
