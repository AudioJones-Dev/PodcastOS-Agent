# Full Production Cycle Workflow

## Purpose

Defines the full repeatable workflow for one podcast episode cycle.

## Workflow

```txt
Client Bible
-> Topic Cluster
-> Episode Plan
-> Production Sheet
-> Pre-Production Meeting
-> Shoot
-> File Ingest
-> Edit
-> Transcript
-> Repurposing
-> QA
-> Publishing
-> Distribution Log
-> Analytics
-> Topic Refresh
```

## Phase 1 - Client Bible Review

Owner: Podcast OS Producer Agent

Actions:

- Confirm Client Bible exists
- Confirm ICP exists
- Confirm offer map exists
- Confirm topic clusters exist or trigger topic strategy workflow

## Phase 2 - Topic Selection

Owner: Topic Strategy Agent

Actions:

- Review current topic cluster
- Score topic opportunities
- Recommend next episode
- Request human approval

## Phase 3 - Episode Planning

Owner: Episode Planning Agent

Actions:

- Create production sheet
- Create host brief
- Create episode outline
- Identify CTA
- Identify clip opportunities
- Request approval

## Phase 4 - Production

Owner: Human Operator + Production Coordinator Agent

Actions:

- Prepare shoot checklist
- Confirm equipment
- Confirm schedule
- Record episode
- Transfer raw files
- Log production notes

## Phase 5 - Post-Production

Owner: Post-Production Agent

Actions:

- Ingest files
- Prepare edit project
- Apply edit template
- Export long-form episode
- Generate transcript
- Create thumbnail
- Generate clips

## Phase 6 - Repurposing

Owner: Repurposing Agent

Actions:

- Create blog post
- Create social captions
- Create carousel ideas
- Create newsletter draft
- Create quote graphics prompts

## Phase 7 - Publishing

Owner: Publishing Agent

Actions:

- QA title, description, thumbnail, CTA, links
- Upload long-form episode
- Publish blog
- Schedule social clips
- Log publishing URLs

## Phase 8 - Analytics

Owner: Analytics Agent

Actions:

- Pull performance data
- Summarize results
- Identify strongest topics
- Identify weak assets
- Recommend next content move

## Completion Criteria

The cycle is complete when:

- Episode is published
- Repurposed assets are distributed
- URLs are logged
- Analytics file is initialized
- Next-cycle recommendation exists
