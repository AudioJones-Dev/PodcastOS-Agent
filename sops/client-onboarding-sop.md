# Client Onboarding SOP

## Purpose

Create the operating foundation for a new Podcast OS client after acceptance.

## Trigger

A client onboarding cycle begins when:

- A lead is approved as a client
- The service tier is confirmed
- Discovery has been scheduled or completed
- The operator approves folder creation

## Inputs

- Approved lead intake
- Client name
- Service tier
- Primary contact
- Brand assets
- Discovery notes or questionnaire
- Contract or scope notes

## Procedure

### Step 1 - Confirm Acceptance

Verify that the client has been accepted by a human operator.

### Step 2 - Create Client Folder

Create the client folder using the required client folder schema.

### Step 3 - Collect Source Materials

Place brand assets, discovery notes, website links, and initial references in the correct folders.

### Step 4 - Start Client Bible

Initialize the Client Bible files and flag missing sections.

### Step 5 - Assign Next Workflow

Route the client to discovery or Client Bible build depending on readiness.

## Outputs

- Client folder
- Client Bible starter files
- onboarding-status.md
- missing-inputs.md

## Completion Criteria

The SOP is complete when the client folder exists, the Client Bible has been initialized, and the next workflow has an assigned owner.
