# Post-Production SOP

## Purpose

Convert raw recording assets into review-ready episode, transcript, thumbnail, and clip inputs.

## Trigger

Post-production begins when:

- Raw files are ingested
- Production notes are available
- The operator assigns an edit cycle

## Inputs

- Raw files
- Production notes
- Episode outline
- Host brief
- Brand assets
- Editing requirements
- Export requirements

## Procedure

### Step 1 - Confirm Raw Assets

Verify file presence, naming, format, and backup status.

### Step 2 - Prepare Edit Project

Create or update the edit project folder and note the edit version.

### Step 3 - Edit Long-Form Episode

Coordinate cleanup, pacing, audio, video, branding, and export.

### Step 4 - Generate Transcript

Create a transcript and place it in the episode folder.

### Step 5 - Prepare Review Package

Package episode export, thumbnail, transcript, and clip candidates for review.

### Step 6 - Request Approval

Request edit and thumbnail approval before publishing.

## Outputs

- edit-status.md
- transcript.md
- clip-candidates.md
- post-production-qa.md
- review-package.md

## Completion Criteria

The SOP is complete when post-production assets are ready for approval and all known issues are documented.
