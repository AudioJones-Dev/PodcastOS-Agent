# Client Folder Schema

## Purpose

Every client must receive a structured folder that acts as the operational spine for their podcast production system.

## Folder Structure

```txt
client-name/
|
+-- 00_CLIENT_BIBLE/
+-- 01_BRAND_ASSETS/
+-- 02_RESEARCH/
+-- 03_EPISODES/
+-- 04_TEMPLATES/
+-- 05_DISTRIBUTION/
+-- 06_REPORTING/
```

## Required Files

### 00_CLIENT_BIBLE

```txt
client-profile.md
brand-guidelines.md
offer-map.md
ideal-client-profile.md
messaging-notes.md
discovery-summary.md
```

### 02_RESEARCH

```txt
seo-keywords.md
aeo-queries.md
competitor-research.md
audience-pain-points.md
trending-topics.md
topic-clusters.md
```

### 03_EPISODES

Each episode folder must contain:

```txt
production-sheet.md
outline.md
host-brief.md
raw-footage/
edit-project/
transcript.md
show-notes.md
blog.md
thumbnail/
clips/
captions/
social-posts/
publishing-checklist.md
analytics.md
```

## Rule

No client deliverable should live outside the client folder unless explicitly linked in the Client Bible.
